# exercises

本目录保存为学习目的自行编写的独立 C++、CMake、性能分析和 CUDA 实验。

## 每个练习应包含

- 学习目标和前置知识；
- 当前掌握层级；
- 独立源码和构建说明；
- 使用的编译器、关键编译选项和运行环境；
- 输入数据的生成方式或公开来源与许可；
- 正确性验证方法和结果；
- 基准测试方法，包括预热、重复次数、计时范围和统计方式；
- 性能分析观察、限制和下一步问题。

掌握层级统一使用：

1. 看过；
2. 能够解释；
3. 能够独立实现；
4. 能够分析正确性与性能。

## 实验规则

- 先验证正确性，再测量性能。
- 所有代码必须独立编写；不得改写、摘录、复刻或反推公司源码和未公开实现。
- 只能使用合成数据或许可与来源明确的公开数据。
- 不得使用客户数据、内部测试数据、公司模型、截图、内部名称、内部路径、账号或凭据。
- 性能结果不得包含能够识别公司项目、客户、设备或内部环境的信息。
- 当前项目不涉及点云，不创建点云练习。
- 碰撞检测重构尚未正式分配，不把它假设为确定练习。
- 生成的构建产物、CUDA 中间产物、性能分析报告、本地数据和模型不得提交；相关模式由根目录 `.gitignore` 覆盖，但提交前仍需人工复核。
