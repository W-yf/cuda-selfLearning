# notes

本目录保存学习笔记、概念解释、数学推导、阅读摘要和公开资料的引用记录。

## 当前入口

- [knowledge-map.md](knowledge-map.md)：长期主线的知识依赖、四类优先级、目标层级和证据门槛。
- [capability-baseline.md](capability-baseline.md)：基于已确认事实的能力基线、证据缺口和 B1–B7 验证结论；当前等待 Stage 1 用户确认。

## 建议内容

- 主题、日期和当前掌握层级；
- 用自己的语言给出的概念解释；
- 必要的公式、假设、边界条件和推导；
- 与独立练习、正确性验证和性能分析之间的链接；
- 仍未解决的问题；
- 公开资料的来源和许可信息。

掌握层级统一使用：

1. 看过；
2. 能够解释；
3. 能够独立实现；
4. 能够分析正确性与性能。

## 保密与公开要求

- 不记录任何公司源码、客户数据、内部文档、模型、截图、名称、内部路径、账号、凭据或未公开实现细节。
- 不粘贴工作材料后再尝试脱敏；只从公开知识和独立思考重新组织笔记。
- 不确定是否可公开的内容一律不写入。
- 当前项目不涉及点云，不加入点云学习笔记。
- 碰撞检测重构尚未正式分配，不把它作为既定学习任务或案例。
